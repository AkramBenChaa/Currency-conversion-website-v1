# Currency Converter

A simple currency-conversion web application built with **HTML, CSS, and JavaScript**.

The application uses the **Frankfurter API** to retrieve currency information and exchange rates.

## Features

- Select a base currency
- Select a target currency
- Convert an entered amount
- Retrieve exchange rates from an external API
- Support available currencies provided by the API
- Store the last selected currencies
- Responsive interface
- Handle invalid conversion results

## Technologies

- HTML5
- CSS3
- JavaScript
- Fetch API
- Frankfurter API
- Promises
- JSON
- DOM Manipulation
- Local Storage

## What I Practiced

- Working with external APIs
- Asynchronous JavaScript
- `fetch()` and Promises
- JSON data handling
- Dynamic `<select>` options
- DOM manipulation

- Input validation and error handling

## Run the Project

Open `index.html` in a modern web browser.

An internet connection is required because exchange-rate data is retrieved from the Frankfurter API.
